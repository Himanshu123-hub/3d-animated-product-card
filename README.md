# 👟 3D Animated Product Card

## 📌 Project Overview

The **3D Animated Product Card** is a modern and interactive product showcase UI built using HTML5 and Advanced CSS3. This project features a stylish sneaker product card with smooth 3D hover effects, floating animations, glassmorphism, gradient backgrounds, and attractive button interactions.

The main goal of this project is to practice advanced CSS properties and create an engaging, modern e-commerce product card without using JavaScript.

## ✨ Features

- 🎨 Modern and attractive UI design
- 🔥 3D card hover animation
- 👟 Animated floating product image
- 💎 Glassmorphism effect using `backdrop-filter`
- 🌈 Gradient background design
- ⭐ Product rating display
- 💰 Product price and discount display
- 🛒 Animated Add to Cart button
- ⚡ Smooth hover transitions
- 📱 Responsive design for mobile devices
- 🌟 Glowing background effects

## 🛠️ Technologies Used

- **HTML5** – For creating the structure of the product card.
- **CSS3** – For styling, animations, transitions, and effects.
- **Advanced CSS** – For 3D transformations, keyframes, glassmorphism, gradients, and responsive design.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR-REPOSITORY-LINK
   ```

2. Open the project folder in VS Code.

3. Make sure the product image is inside the `images` folder.

4. Open `index.html` in your browser.

5. Enjoy the 3D Animated Product Card!
